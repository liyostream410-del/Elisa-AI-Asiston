# Elisa V1 — GitHub Codespaces + Capacitor

This is the V1 web UI packaged as a Capacitor Android project starter.

## Folder structure

```text
Elisa-V1/
├── www/
│   └── index.html
├── .devcontainer/
│   └── devcontainer.json
├── .github/
│   └── workflows/
│       └── build-apk.yml
├── capacitor.config.ts
├── package.json
└── .gitignore
```

## Run the web UI in Codespaces

```bash
npm install
npm run dev
```

Then open forwarded port 3000.

## Create the Android project

```bash
npm install
npx cap add android
npx cap sync android
```

The Android folder is generated by Capacitor; it is intentionally not committed in this starter.

## Build APK

For a local build, the Codespace must have the Android SDK available. The GitHub Actions workflow is included so the repository can build the debug APK in GitHub Actions.

In GitHub: Actions → Build Elisa V1 APK → Run workflow.

The APK is uploaded as an Actions artifact named `Elisa-V1-debug-apk`.

## App ID

`com.elisa.v1`

## V1 scope

The AI model connection remains disabled for V1. The current UI, falling-petal effect, chat/video/settings pages, and YouTube controls are kept as the web layer.
